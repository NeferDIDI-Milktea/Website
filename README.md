# Neferdidi Milkteashop Website

A static, responsive website for Neferdidi Milkteashop. It includes:

- Home and brand-story sections
- Interactive menu categories and listed prices
- 12 branch cards with Google Maps links
- Branch search and area filters
- Instagram, Facebook, and TikTok links
- Responsive mobile navigation

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

No build step or package installation is required. The page uses Google Fonts from an external CDN; the site still works if fonts cannot load.

## Publish with GitHub Pages

1. Create or open the GitHub repository where the site should live.
2. Upload `index.html` to the repository's root folder (the same level as this README).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site; GitHub will show the public URL in Settings → Pages.

## Before publishing

Please verify all branch locations and map links, prices, menu descriptions, contact links, and marketing claims with the brand owner. The page preserves the information in the supplied HTML and does not independently verify it. Update the relevant text in `index.html` before publishing if anything has changed.

## Drink photo matching

Drink photos were matched visually against the supplied photographed menu. Some visually similar drinks (especially layered coffees and cream/slush drinks) may need a final human check before public launch. The menu prices and product names were not changed.
